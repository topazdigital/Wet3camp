Wet3Camp is live on wet3.camp. Treat changes in the imported Replit workspace as development changes; do not publish them without the user's request.

Public profile maps should communicate a general service area, not an exact home location or live position. Any future precise pin should be explicit, owner-controlled, and revocable.

**Why:** The user said the project is live, and publishing exact personal locations can create physical safety and privacy risks, especially for profiles that may not be owner-managed.

**How to apply:** Keep production untouched unless the user asks to publish. For location features, make precision clear and prefer a voluntarily selected approximate area.
