---
name: Homepage content freshness
description: User-stated homepage rule for current content and returning-visitor variety.
---

**Rule:** The homepage should show current profiles and articles from real data, and active live streams should rotate so repeat visitors do not keep seeing the same selection. Do not present hardcoded sample clips as the latest content.

**Why:** The user said repeated homepage content will bore returning visitors.

**How to apply:** Fetch current streams, newest active profiles, and published articles from their APIs. Rotate selections drawn from recent content, and clearly distinguish an active broadcast from an uploaded recorded clip.
