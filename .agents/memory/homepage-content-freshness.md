**Rule:** Keep changing homepage content inside the existing layout; do not add a standalone “Fresh” section unless asked. Keep the rounded live/story rail visible, rotate active streams and real recent clips, and label recent profiles as new rather than live. Keep blog previews on the Blog page unless the user asks otherwise.

**Why:** The user wants returning visitors to see current content but corrected the addition of a separate homepage section, asked to preserve the rounded live rail, and chose to keep blogs on the Blog page.

**How to apply:** Use the existing escort browse grid for newest profiles and the rounded rail for active streams, recent clips, or clearly marked new profiles when no stream or clip is available. Never label an inactive profile or recorded clip as live.
