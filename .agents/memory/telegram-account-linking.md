---
name: Telegram account linking
description: Wet3Camp's Telegram sign-in and existing-account linking expectations
---

Most escorts are on Telegram, so Telegram should remain a first-class sign-in option. A Telegram identity must attach to one canonical Wet3Camp account, not create a duplicate or change the account's role.

Signed-in users can link Telegram from account security settings. For a first Telegram sign-in, Telegram does not provide an email address: verify the user's email with a one-time code, then link to the existing email/Google account or create an account if the email is new. Do not transfer a Telegram identity that is already linked to another Wet3Camp account.

**Why:** The user wants Telegram login because most escorts use Telegram, while existing email and Google users must keep their current account and profile.

**How to apply:** Keep account linking explicit for signed-in users, require email verification to resolve logged-out users to an existing account, and preserve role/profile data when linking.
